# GameTrack - CRUD Web Application

Projeto simples de gestão de jogos (GameTrack) desenvolvido para a disciplina de Programação Web. Fornece operações CRUD (Criar, Ler, Atualizar, Remover) para gerir um catálogo de jogos.

## Funcionalidades (CRUD)
- Listar jogos
- Adicionar novo jogo
- Editar jogo existente
- Remover jogo

## Tecnologias
- Banco de dados : Firebase 
- Frontend: Angular
